# client-email

Rewrites rough email drafts in the style of past emails to one client (Priya).

- `emails/` holds the examples, one email per `.txt` file. Never edit or delete existing ones.
- `style-notes.md` holds the style rules.
- The whole process lives in `.claude/skills/draft-email/SKILL.md`.
- `draft.txt` is a temporary file. It is not part of the dataset.
